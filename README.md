# Version de consultation du portail d’accréditation

Snapshot de l’interface corrigée du dépôt Seydoutra/accreditation, branche
fix/core-accreditation, commit 8d9e8eb7ca30ef05e9055db7fc7e28174f100368.

Cette version statique sert uniquement à consulter la plateforme. Les données
sont fictives. Aucun mot de passe, dossier, justificatif ou décision n’est envoyé
à un serveur. La vue participant et la vue administration peuvent être choisies
depuis « Connexion ».

Le serveur Python/SQLite complet demeure dans le dépôt GitHub. Il n’est pas
déployé par ce site de consultation. Un hébergement adapté, SMTP et HTTPS seront
nécessaires pour enregistrer des dossiers réels.

La bibliothèque QR est conservée une seule fois, avec ses notices de licence.
